# Adding Agents

## The idea

What do we actually add to a project when we add an AI agent rather than a person? We borrow the language of teams, colleagues, staffing, delegation, and headcount, but those metaphors carry assumptions about how someone learns the work, keeps context, coordinates with others, and takes responsibility. An agent can change some of those costs and introduce others. The essay should ask where our familiar project-management metaphors still help and where they give us the wrong picture.

The starting point is Jan van den Berg's [“The Mythical Man-Month in the age of AI”](https://j11g.com/the-mythical-man-month-in-the-age-of-ai), which revisits Brooks's warning about adding people to a late software project. The comparison opens a broader question about human and agent participation: when does another participant increase useful capacity, and when does it create more specification, coordination, review, or integration work?

The working angle is that **agent count tells us little about effective project capacity on its own**. Task boundaries, shared state, dependencies, context, verification, and decision authority may be more useful things to examine. The piece needs concrete examples of both successful parallel work and work made harder by adding agents.
