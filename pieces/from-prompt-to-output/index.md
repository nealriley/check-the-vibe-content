# From Prompt to Output

## The idea

Follow one request through a language-model service: how input becomes tokens, how context shapes the response, what inference and generation do, and why a useful answer can still contain uncertainty or error. A concrete example should make the steps visible without suggesting that every AI product follows an identical path.

This piece concentrates on use of an already trained model. [How Machines Learn](../how-machines-learn/index.md) explains how models are prepared and changed over time.
