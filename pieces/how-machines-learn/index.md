# How Machines Learn

## The idea

An accessible explanation of the different processes people group under “learning.” Start with how training changes a model, then distinguish later changes such as fine-tuning from what happens when a model uses examples in a prompt or retrieves information while responding. The reader should leave able to ask what actually changed, when, and for how long.

The piece can connect to [Feedback, Control, and Cybernetics](../feedback-control-and-cybernetics/index.md) without equating every feedback loop with model learning. [From Prompt to Output](../from-prompt-to-output/index.md) takes over when a trained system is used for a particular request.
