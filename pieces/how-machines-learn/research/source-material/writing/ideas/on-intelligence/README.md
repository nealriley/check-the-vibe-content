# On Intelligence

## The seed
Machine intelligence is neither a god nor mere autocomplete — it is **lab-grown intelligence**: adaptive fit-making produced by machine processes acting on inherited human cultural material. Uses Dennett's Darwinian→Skinnerian→Popperian→Gregorian ladder to map how organisms *and* machines become smart.
