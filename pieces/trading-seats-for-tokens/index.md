# Trading Seats for Tokens

## The idea

An essay about the rise of **agentic consumption alongside human consumption**. Software and digital services are often organized around a person using an account, occupying a seat, visiting an interface, and deciding when to act. What changes when agents become substantial consumers of those services: reading content, calling tools and APIs, running workflows, and spending compute on a person's or organization's behalf?

The title connects two ways of buying capacity: access for a named human and metered machine activity. The piece should follow where usage, expenditure, attention, and commercial value move as agents do more of the consuming. It can examine software subscriptions, content and data access, and model or tool usage, while keeping the human beneficiary and payer visible.

The proposed trend needs evidence. More agent activity might replace some human use, create additional demand, or change the interface through which the same service is consumed. Fewer seats, more tokens, higher total spending, and better outcomes are separate possibilities to investigate.
